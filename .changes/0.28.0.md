## 0.28.0 - 2026-08-31
### Added
* CI: weekly "Changie pin check" workflow opens a tracking issue when the Changie pin in release-prepare.yml falls behind the latest upstream release; it only notifies (#283)
### Fixed
* release workflows: version regex now rejects zero-padded components (1.0.00), which sort -V ordered after 1.0.0 and let a duplicate non-SemVer release through (#276)
* release-finalize: concurrency is now a job-level global FIFO queue (queue: max) so runs cannot race across versions; fork and unrelated PRs get isolated groups (#277)
* release-prepare: when opening the PR fails after the push, the run deletes its release/v<version> branch (lease-protected) so Prepare can simply be re-dispatched (#278)
* release-prepare: Changie is pinned to v1.26.0 on the changie-action step instead of latest, so an upstream release cannot change or break the batched changelog unreviewed (#279)
* release-finalize: the tag is verified against the merge commit before a state is chosen, a release without its tag fails, and tag enumeration fails closed on lookup errors (#280)
* release-prepare: the tag/branch existence probes now fail the run when git ls-remote itself errors (network, auth) instead of reading the failure as "absent" and proceeding (#282)
