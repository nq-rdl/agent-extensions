## 0.14.0 - 2026-06-23
### Added
* Add `/skill:audit` — a non-inferable-value review skill, the read-only `skill-auditor` subagent, and an advisory PostToolUse hook nudging the audit when a skills/**/SKILL.md changes; folded into the existing `skill` bundle alongside review and report-issue.
* cc-web-setup: portable plugin provisioning for other repos — a curated team-externals settings template (`settings.externals.json.tmpl`) alongside the rdl baseline, an `assets/marketplaces.json` source of truth, and a `web-settings.sh` guard helper that enforces marketplace-consistency (every enabled plugin's marketplace declared, #157) and strips self-referential marketplaces (#149); plus a `references/web-setup.rst` platform/architecture/anti-patterns reference
* 
### Changed
* Compress `conventional-commits` to the non-inferable delta: drop the spec recital (and references/guidance.rst), add the commit-type to changie-kind/release-flow mapping and the feat/fix/chore edge calls; link the spec instead of restating it.
* Compress `r-expert` to the non-inferable delta: drop the tidyverse style-guide recital (and references/style-quick-ref.rst); keep the R-version-pinned high-drift items, the cli/styler/arrow toolchain preferences, and the r-lib-*/shiny-* delegation pointers.
* Trim `go-naming` ~50% to the high-drift items: the initialisms casing table, getter/stutter/receiver rules, and the Summary Checklist; link Effective Go for the rest instead of restating it.
* Adopt a skill-authoring convention (CONTRIBUTING.md 'Skill content conventions'): prefer the non-inferable delta (Biggs + SkillsBench), pin versions in compatibility:, and add a verify-canonical guard; cross-linked from AGENTS.md.
* Cleanup of old files and folders
### Removed
* Remove the `zod` skill and bundle: it restated textbook Zod and taught the deprecated pre-Zod-4 API (z.string().email(), error.format()) with no version pin, and conflicted with the no-new-TypeScript policy.
### Fixed
* `sync-plugins.sh` now writes and drift-checks (bytes + exec mode) the live `.claude/scripts/` cc-web-setup hook copies from canonical, closing the silent-drift gap (#166).
