## 0.16.0 - 2026-06-24
### Added
* Add a `/claude-code:web-setup` and `/rdl-team:cc-setup` plugin-discovery pass plus a new `marketplace-scout` agent that enumerates the RDL marketplace and the team's extra marketplaces, inspects the repo's stack, and suggests an always-useful baseline (pr-review-toolkit, gh@rdl, worktrunk, the applicable LSP) and language-matched plugins; the baseline + marketplace list are tracked in `marketplaces.json` (now shipped with both setup skills)
### Fixed
* Fix the cc-web-setup `install-deps.sh` plugin self-heal for external marketplaces blocked by the in-sandbox GitHub proxy (failure mode #4): `claude plugin marketplace add owner/repo` is a git clone and 403s for any repo that is not the session's own — independent of the environment's network-access level and unaffected by `GH_TOKEN`. On a git-add 403, `register_marketplace_via_tarball` now fetches the marketplace over HTTPS (`api.github.com`/`codeload`, both Trusted-allowlisted) and registers it from a local path (no git); the name-reserved `claude-plugins-official` short-circuits with a vendoring pointer. Documents the git-proxy repo-scoping failure mode and the `.claude/skills/` vendoring escape hatch in SKILL.md and references/web-setup.rst.
