## 0.20.0 - 2026-07-02
### Added
* Add the opencode-dev plugin — 7 skills for developing OpenCode (opencode.ai) solutions (plugin, sdk, agent, tools, skill, policies, delegate) plus a UserPromptSubmit doc-review hook
* docs/releasing.md release runbook covering cutting a release, partial-failure recovery, and rollback
* "At a glance" plugin/description table at the top of the generated `docs/bundles.md`, emitted by `generate_bundles_doc.py` from the registry (linked to each plugin section)
* Release PR guard workflow — pre-merge check that a release/v* PR matches its branch version and is strictly newer than main's VERSION, so stale release PRs go red before merge
* Per-fragment changie body length cap (200): `.changie.yaml` body.maxLength guards `changie new`; a lefthook pre-commit hook + CI check (check_changie_length.py) lint added fragments
### Changed
* Plugin consolidation renames invocations: `docs@rdl` → `tech-writing@rdl`; `/gh:go` → `/gh:actions-go`; `/skill:audit|review|report-issue` → `/claude-code:skill-audit|skill-review|skill-report-issue`
* Plugin consolidation (34 → 29): GitHub Actions work now lives under `gh` — `github-actions-expert` home, `se-gitops-ci-specialist` guest
* Plugin consolidation: the former `research` agents move to `planning` (`research-technical-spike`) and `claude-code` (`prompt-builder`)
* Release flow replaced: dispatching release-prepare opens a reviewable release/v* PR; merging it tags + publishes (no local tagging)
### Removed
* Plugin consolidation retires plugins `github-actions@rdl` (merged into `gh`), `hooks@rdl` (forced-eval hook ships only via the `/rdl-team:cc-setup` skill), and `skill@rdl` (folded into `claude-code`)
* Plugin consolidation retires subject plugins `research@rdl` (agents rehomed to `planning`/`claude-code`) and `review@rdl` (a code-review plugin from an external marketplace covers it)
* Plugin consolidation removes five review-only agents: `wg-code-alchemist`, `critical-thinking`, `doublecheck`, `agent-governance-reviewer`, `se-responsible-ai-code`
* Plugin consolidation migration: install the replacement subjects (`gh@rdl`, `claude-code@rdl`, `planning@rdl`) or reinstall `rdl@rdl` to pick up the regenerated set
### Fixed
* opencode-dev: fix reference pointers (.md → .rst) in the opencode-sdk and opencode-agent skills
* opencode-delegate: harden the skeleton — create cache dir before save, use fileURLToPath not import.meta.filename, fix SDK session.create body/data shape, handle unknown job ids in result/cancel
* Doc drift: refreshed the stale `go`-bundle example in AGENTS.md — it showed `go-gh` in the `go` bundle as `/go:gh`; it lives in `gh` as `/gh:go` since #115
* Doc drift: replaced the dangling `docs/specs/*` links in CONTRIBUTING.md (the specs were removed in the pre-v0.14.0 cleanup)
* Repo-local Python is now managed by pixi: the default environment provides python + pyyaml on linux-64/osx-arm64/osx-64; the Zensical docs toolchain moved to a linux-64-only docs feature/environment
* pixi: lefthook and the docs build now invoke every registry script via `pixi run`
