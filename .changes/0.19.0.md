## 0.19.0 - 2026-07-01
### Added
* New `.claude/` PreToolUse hook reminds contributors to review AGENTS.md before editing dev tooling — guards against settings/docs drift
* New AGENTS.md section separates the published marketplace from the `.claude/` contributor tooling, pointing to `CONTRIBUTING.md` and `docs/`
* `cc-agent-create` / `claude-code:agent-create` skill — a guided, CI-green pipeline for adding a catalog subagent under `agents/<name>/agent.md`. Covers import-and-normalize (adapting an upstream `github/awesome-copilot` `.agent.md`) and from-scratch authoring, wires the agent through the registry → plugin-tree → manifest → changelog → validate pipeline by calling the existing scripts, and installs a session-scoped Stop + PostToolUse guard (auto-torn-down) so the session cannot end with a half-wired agent
