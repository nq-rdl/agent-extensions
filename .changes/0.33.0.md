## 0.33.0 - 2026-09-22
### Added
* Opt-in local pre-push job (`CLAUDE_EVAL_ENABLE=1`) evaluates plugins whose suite or tree changed, staged from the pushed commit; no CI workflow (#334)
* `scripts/eval-claude-plugin.sh` runs `claude plugin eval` on a staged plugin copy with suites from `evals/claude/<plugin>/`, leaving Claude and Codex generated trees untouched (#334)
* `scripts/generate_eval_graders.py` builds eval regex graders from a readable `graders.spec.yaml`, with fixtures graded in both Python and Node (#335)
* Three more `go:naming` eval cases (error naming, expensive getters, interfaces); the skill lifts scores by 0.20 to 0.50 on three of four cases and 0 on one the model already handles (#335)
* Opt-in string-SQL guard checks lift coverage for Claude writes and Codex patches; disabled by default (#333)
* New `data-request:lift` classifies pinned-library gaps and records confirmed library follow-ups at enquiry close-out (#333)
* Schema-2 lift ledgers capture evidence before hand SQL while preserving schema-1 review compatibility (#333)
### Changed
* `go:naming` now shows that the don't-stutter rule covers types and constructors; evals had the rename skipped about half the time, now 10/10 with the skill (#334)
* Default `EVAL_MAX_COST_USD` ceiling for the eval runner raised from 2 to 5, since the four-case `go` suite costs about 2.20 per run (#335)
### Fixed
* Eval grader generation detects orphaned outputs and rejects unsafe capturing groups (#335)
* Go naming eval graders accept idiomatic alternatives and catch incomplete identifier renames (#335)
* Expensive-getter eval fixture preserves row scanning and query results (#335)
* Go naming evals reject uppercase constants and redundant counter names (#335)
* Go eval graders select top-level rewritten files without treating nested fenced examples as answers (#335)
* Go naming evals accept contextual validator names while preserving constant export visibility (#335)
* Go naming evals accept renamed context parameters and leading block comments while rejecting underscore type suffixes (#335)
* Skips paid plugin evaluations for deletion-only pushes (#334)
* Preserves separate plugin evaluation reports for each pushed commit (#334)
* Rejects long Go receiver names in the naming evaluation (#334)
* Pre-push Claude evals skip mismatched runner revisions and fail in strict mode (#334)
* Pre-push Claude evals deduplicate commits shared by branches and tags (#334)
* Plugin evals compare existing refs with their remote tips to avoid repeating unchanged suites (#334)
* Eval graders accept Markdown closing fences longer than their opening fences (#334)
* The Go query naming grader rejects rewrites that remove database operations or discard results and errors (#334)
* Custom eval report paths retain each plugin and revision; spend limits explicitly apply per plugin per revision (#334)
* Go naming eval graders reject missing behavior and accept idiomatic retry constants and spaced code fences (#334)
