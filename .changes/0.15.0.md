## 0.15.0 - 2026-06-23
### Added
* Added the `rdl-team` plugin with `/rdl-team:cc-setup` to onboard users onto the RDL Claude Code setup (#115)
* Added the `skill-creator` plugin from `claude-plugins-official` to `.claude/settings.json` (#170)
* Enabled the `plugin-dev@claude-plugins-official` plugin in `.claude/settings.json` (#171)
* Add `/claude-code:create-workflow` skill — guides creating, saving, and reusing Claude Code dynamic workflows: a decision gate for workflow vs subagent/skill/agent-team, the `ultracode` author-and-save loop, `.claude/workflows/` distribution rules (including the no-plugin-bundling reality), `args` parameterization, and runtime/permission/cost constraints
* Cross-listed existing agents into more relevant plugins — `wg-code-sentinel` and `github-actions-expert` into `go`, `terraform-iac-reviewer` into `review`, and `se-gitops-ci-specialist` into `argo-cd` (#137)
* Add `/claude-code:pipeline` skill — a decision framework for reproducible multi-step flows: single ordered skill vs multiple step commands, the marker-file + hook gating pattern for enforced ordering, and when to escalate a step to subagents, an agent team, or a dynamic workflow
### Changed
* Moved `go-gh` from `/go:gh` to `/gh:go` (#115)
* Renamed the `git` plugin to `gh` so its skills invoke as `/gh:*` (#115)
* Reworked the `repo-architect` agent from a Copilot/VS Code scaffolder into a GitHub repo bootstrap/audit agent and moved it from the `planning` plugin to `gh`, where it delegates to the gh skills (#137)
* Optimized all 30 agents for Claude Code — set `model` per agent (opus for the reasoning/review/architecture tier, sonnet for the execution/ops/docs tier), added `effort: xhigh` to the reasoning tier, fixed an out-of-spec `color` value, and de-branded the JARVIS persona in the `wg-code-*` agents (#186)
### Removed
* Removed the unused `api-architect` agent (niche API-client code generator, no plugin uptake) (#137)
* Removed the `gem-reviewer` agent from the `review` plugin; it duplicated `wg-code-sentinel` (#137)
### Fixed
* forced-eval-hook now parses `>-` folded descriptions, no-ops on an empty catalogue, and uses portable cache-freshness checks (#115)
* Fixed a Claude Code on the web cold-start race where the SessionStart plugin self-heal (`ensure_plugins`) ran before `extraKnownMarketplaces` were registered, so installs failed against an empty marketplace registry and the failure was misreported as a network issue; the hook now registers every declared marketplace with `claude plugin marketplace add` before installing (#181)
* cc-web-setup: documented the cold-start marketplace-registration race and the self-heal's add → update → install chain in SKILL.md and the reference doc, corrected the stale single-failure-mode guidance, and added a matching anti-pattern (follow-up to #181)
* Agent skill-preload references now resolve in every plugin. `sync-plugins.sh` rewrites each agent copy's `skills:` frontmatter to the target plugin's leaves and drops skills the plugin doesn't ship, so cross-listed agents no longer preload canonical names that don't exist in that plugin — `repo-architect` → `go` (gh), `wg-code-sentinel` → `secure` (go) / none (review), `se-gitops-ci-specialist` → `manage` (argo-cd) (#186)
