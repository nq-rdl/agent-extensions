## 0.29.0 - 2026-08-31
### Added
* redhat plugin (#261): fetch Red Hat documentation and Customer Portal (KCS) content with your own offline token via curl/wget on macOS and Linux.
* /redhat:fetch-docs skill: routes docs.redhat.com URLs to the product source repo (AAP, OpenShift) and solution/article ids to the KCS API; search: and docs-text: targets.
* /redhat:setup skill: checks OS, fetcher, and credential presence; guides generating, storing (Bitwarden/keychain/0600 file), loading, and verifying the offline token.
* redhat-docs-fetcher agent: autonomous preflight → route → fetch → extract → provenance executor for Red Hat docs; stops at /redhat:setup when no credential is loaded.
* redhat hooks: SessionStart preflight context and a PreToolUse guard (curl/wget only, no token leakage, credential required for subscriber-only Portal content).
