* /sql-review:bootstrap (#127) interviews the Data Engineer into a scope.json/scope.md (intent, inputs, outputs, assumptions, open questions), each assumption human-confirmed.
* /sql-review:analyse (#130) reviews SQL against its scope into review.json/review.md; each rerun diffs the snapshot, walks through changes and reassesses every item.
* /sql-review:explain (#128) walks the Data Analyst through reviewed SQL step by step, cross-referencing assumptions and limitations by id, and resumes from what changed.
* sql-review hooks: a SessionStart preflight reporting stale reviews, and a PreToolUse guard that only lets review/scope JSON be written with complete confirmation records.
