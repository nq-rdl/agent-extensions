## 0.8.0 - 2026-05-30
### Removed
* Remove all Gemini CLI support after its discontinuation — the `.gemini/` extension tree, `GEMINI.md`, the `gemini-cli` skill, and the `gemini-cli-go` MCP server. The catalog now targets Claude Code exclusively.
* Removes the `pi-rpc` skill, MCP server, and prebuilt pi-server binaries — pi.dev support dropped from `dev-tools` (#97)
### Fixed
* Rewrite forced-eval-hook to emit an advisory skill catalogue via additionalContext instead of coercive prompt-injection-shaped prose, gated on use intent (#78)
* Harden the skill sync so an upstream rename or removal no longer silently breaks it — `sync-plugins.sh` now warns and skips unresolved registry references (and prunes stale plugin copies) instead of aborting before the PR is opened, `validate.yml` remains the authoritative gate, and `sync-skills.yml` opens a tracking issue on failure.
