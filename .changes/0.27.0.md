## 0.27.0 - 2026-07-28
### Added
* codex plugin: defect logging library, classifier, and CLI tool to capture, classify, and manage plugin failure markers
* codex plugin: defect-report-hook surfaces unreported failures to Claude Code with nudge to report-defect skill
* codex plugin: defect-report hook now ships a .sh wrapper that preflights the Node >=18.18.0 floor, matching the other two hooks
### Fixed
* Document the first-party defect-logging files as original nq-rdl work carved out of the vendored Apache-2.0 codex tree.
* codex plugin: resolveWorkspaceRoot no longer returns an empty root when the git toplevel probe fails, which collapsed every workspace onto one shared state dir
* codex plugin: the surfaced-marker lock now waits on a wall-clock deadline instead of an attempt budget, so a loaded machine no longer declines marks it had time to write
* codex plugin: hook wrappers preflight the Node floor with one `node -p` instead of two, saving a ~40ms Node start-up on every hook invocation
* codex plugin: the defect-report hook now fires on PostToolUseFailure. A recorded defect exits non-zero, which raises that event and not PostToolUse, so the nudge missed the turn it was written.
* codex plugin: the defect-report hook is now wired for SessionStart, so a defect recorded in one session surfaces at the start of the next instead of waiting for a SubagentStop.
### Security
* CI: bumped pinned actions to current majors — checkout v7.0.1, setup-node v7.0.0, setup-go v7.0.0, github-script v9.0.0. Supersedes dependabot PRs #253, #252, #246, #245.
* CI: every third-party GitHub Action is now pinned to a full commit SHA with a version comment, replacing mutable floating tags across all workflows and docs.yml.tmpl.
* Tests: the codex test helper never spawns through a shell now, so environment-derived absolute paths cannot be re-parsed by cmd.exe (CodeQL js/shell-command-injection-from-environment).
