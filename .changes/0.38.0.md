## 0.38.0 - 2026-10-04
### Added
* Script Red Hat sops/age installation and private identity creation, resolve recipients automatically, and report TPM access with offline shim coverage.
* Tag SkillSpector findings with their OWASP Agentic Skills Top 10 risk in code scanning and summarise them per risk in the CI job summary.
* Add the adr plugin with /adr:record: consent-gated MADR 4.0.0 records, supersession, "why did we choose X?" retrieval, and merged-spec archival (#202).
* Add adr-scan.sh to find the ADR directory and the next number, which is never reused: index rows, deleted files and other branches keep theirs.
* Choose MADR 4.0.0 over Structured MADR for ADRs. New logs use NNNN-title.md in docs/adr; existing logs keep their own name style and format.
* Add /pi:rescue: forward investigation or fix requests to pi with resumable per-checkout sessions and GPT-5.6 prompting guidance for OpenAI models.

* Bump the pinned SkillSpector scanner to the 2026-10-02 main commit.

* Breaking change: /planning:record-decision no longer exists.
