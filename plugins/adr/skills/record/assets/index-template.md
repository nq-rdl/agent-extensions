# Architecture decision records

Each record follows [MADR 4.0.0](https://adr.github.io/madr/) and is named
`NNNN-title-with-dashes.md`. Numbers are never reused, so rows are never
deleted, even when a record file is removed. Accepted records are not
rewritten: a change of mind is a new record that supersedes the old one.
